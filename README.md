# PPAI-DSI

---

El puerto para ejecutar el proyecto es 8081 para no obstruir al puerto de la api que nos da la información de los bolsines

Estamos usando una arquitectura monolítica en capas.

Para la persistencia de datos estamos usando JPA e Hibernate y SQLite

En el backend estamos haciendo uso de Spring boot y en el front estamos usando React

Para poder ejecutar este proyecto, primero tenemos que levantar la API de la ubicación de los bolsines en el puerto 8080 y después podemos ejecutar el proyecto correctamente
